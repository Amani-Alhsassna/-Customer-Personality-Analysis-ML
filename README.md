Machine Learning Assignment 2
This repository contains my solution for Assignment 2 in the Machine Learning course.
In this assignment, I used the Customer Personality Analysis dataset to apply different machine learning techniques. I started by cleaning the data, handling missing values, creating new features, and encoding categorical variables.
Then, I built regression models to predict customer spending, classification models to predict customer response, and K-Means clustering to group customers into different segments. Finally, I compared the models using different evaluation metrics and visualizations.
